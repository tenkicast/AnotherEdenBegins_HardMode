===============================================================================
  ANOTHER EDEN BEGINS - HARD MODE
  Changelog
===============================================================================


-------------------------------------------------------------------------------
  1.0.1  -  Full game
-------------------------------------------------------------------------------
Documentation release. No gameplay, balance or tuning values were changed, and
no hook was added, removed or altered.

  * Confirmed working on the full release of Another Eden Begins. The game's
    code and the interop surface the mod binds to are unchanged from the demo
    build, so the same plugin runs on both.

  * Documentation no longer describes the mod as demo-only, and no longer
    states how far it has been playtested.

  * Extreme is now described as the least tested tier rather than as untested.

  * Install paths in the documentation point at the full game folder.

  * Fixed a broken Nexus download link in README.md.

If you are upgrading from 1.0.0, your existing config file is kept as-is.
BepInEx never overwrites settings a config already has, so nothing you have
tuned will be reset.


-------------------------------------------------------------------------------
  1.0.0  -  First public release
-------------------------------------------------------------------------------

  * Three difficulty tiers: Hard, VeryHard and Extreme, plus Off.
    Starts on Hard.

  * Enemy health, attack, defence and final damage are all scaled per tier.
    Ordinary enemies roll their own values from their enemy ID, so a given
    enemy is always the same across encounters, reloads and saves.

  * Bosses are tuned on their own dials and never roll randomly, so a boss
    fight is decided by play rather than by luck.

  * Scaling grows with enemy level. Early enemies keep gentler numbers, so the
    opening hours are not punished with values meant for the endgame.

  * Out-levelling content no longer trivialises it. The vanilla damage bonus
    for being above an enemy's level is removed, while the penalty for being
    below it is kept.

  * Eight specific story encounters are hand-tuned, for fights that are harder
    for reasons raw numbers cannot see - such as battles where healing is not
    available to you.

  * Fleeing a battle always succeeds. Battles the game does not let you flee
    are unaffected.

  * Optional experience and money multipliers, OFF by default.

  * Every setting is adjustable in the config file, and every one is explained
    there in plain language.

  * No game file is modified. The mod works entirely through in-memory hooks,
    and deleting it restores the vanilla game exactly.

  KNOWN LIMITATIONS
  * EXTREME IS THE LEAST TESTED TIER by some distance. Hard and VeryHard are
    the most played.
  * Enemy shield / break counts are not scaled yet.
  * Two settings crash the game and are disabled by default, with warnings in
    the config file: Disable Reserve Party HP Regen and Disable Reserve Party
    MP Regen.
  * Requires a BLEEDING EDGE BepInEx 6 build (6.0.0-be.788 or newer). Stable
    BepInEx releases crash on this game. See the README.
